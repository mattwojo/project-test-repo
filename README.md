# Alex Morgan — portfolio template

A responsive, interactive portfolio template built with TypeScript and Vite. It has no UI framework dependency, so the content and visual system are easy to adapt.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`, or preview it with `npm run preview`.

## Customize

- Update the profile copy and project data in `src/main.ts`.
- Adjust colors, typography, and responsive styles in `src/styles.css`.
- Replace the placeholder social and email links in the page footer and contact section.

The template includes keyboard-friendly navigation, a mobile menu, project category filters, project detail dialogs, a persistent light/dark theme toggle, reveal animations, and reduced-motion support.
